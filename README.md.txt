# Genre Museum

A responsive gaming website created as a university Web Development Essentials project.

Genre Museum presents different video game genres and selected games through a responsive and interactive interface.

## Features

- Responsive design for desktop, tablet, and mobile devices
- Dark and light theme
- Theme preference saved using `localStorage`
- Game genre search and filtering
- Interactive game suggestion form
- Client-side form validation
- Responsive navigation
- Automatic and manual banner controls
- Scroll-based navigation
- Links to additional game information

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Bootstrap
